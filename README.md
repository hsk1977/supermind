# 🎮 Supermind - Browser Casual Games Portal

A collection of fun, lightweight, and responsive casual browser games built with **HTML, CSS, and JavaScript**. No installation or downloads required—play directly in your web browser!

🔗 **Play Now:** [https://hsk1977.github.io/supermind/index.html](https://hsk1977.github.io/supermind/index.html)

---

## 🕹️ Featured Games

Here is a list of the games currently available in this collection:

1. **🧠 Pretty Mind (Mastermind)** - A classic code-breaking game where you guess the hidden color combination.
2. **♟️ Checkers** - Traditional board game played on an 8x8 checkerboard.
3. **🔄 Reversi (Othello)** - Strategy board game where you trap your opponent's pieces.
4. **✏️ Hangman** - Word-guessing game to test your vocabulary.
5. **🍉 Fruit Ninja Style** - Action-packed casual slicing mini-game.
6. **🃏 Memory Match** - Card-flipping memory puzzle game.
